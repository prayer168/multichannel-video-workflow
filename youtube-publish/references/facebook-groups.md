# Facebook 社團規則紀錄表

搭配 `facebook-post-safety.md` 的 D 節（社團專用審查）與 D2 節（多社團發布）使用。每個要發文的社團一列；**這張表只是參考，發文前仍要重看該社團的公開規則與最新公告**，與表上不同時以社團現況為準並更新本表。

## 欄位說明

- **社團／網址**：社團全名與網址（以實際頁面為準）。
- **類型**：AI 技術／自然科學／教師教學／其他，決定改寫方向（D 節）。
- **適用頻道**：自然教室、AI Watch 或兩者。
- **原創影片**：允許／禁止／需同意／未確認。
- **YouTube 連結**：允許／禁止／需同意／未確認。
- **自我推廣**：允許／限定時段或專區／禁止／未確認（例如「每週五推廣串」）。
- **管理員同意**：需要／不需要／未確認；已取得時寫日期與方式。
- **發文頻率限制**：社團自訂的上限（例如「每人每週一篇」），沒有寫「無明文」。
- **上次查核**：查核日期與截圖位置。
- **上次發文**：日期與影片名稱，用來檢查 D2 節的間隔。
- **狀態**：可發／REVIEW／暫停／不發，附原因。
- **備註**：被刪或限制的紀錄、管理員回覆等。

任一必要欄位是「未確認」時，該社團的判定為 REVIEW，不自動發布。
