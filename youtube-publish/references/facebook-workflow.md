# Facebook 宣傳文發布

適用於使用者明確要求把交付宣傳文發布到 Facebook 的情況。

## 準備與目的地

- 讀取該片「製作後/臉書宣傳/臉書文_中文.txt」與對應分享圖，將 YouTube 連結占位符換成已核實的實際影片網址。
- 核對使用者指定的個人檔案、粉絲專頁或社團與發文身分。使用者提供截圖時，可從畫面上的名稱與網址辨識目的地，再於實際頁面核對。目的地仍不明時，一次詢問名稱或網址。
- 查閱本專案的 Facebook發布結果.md 與指定頁面，已有同一影片的貼文時先核實，避免重複發布。

## 發布與驗證

1. 優先使用足以完成工作的 connector；否則使用已登入瀏覽器。填入配套文案、實際 YouTube 網址與對應分享圖。
2. 圖片選檔先啟動 filechooser 等待，再點圖片上傳控制。只有圖片區出現時，繼續點該區的新增圖片控制。可用語意控制無反應時，依新截圖定位。
3. 檢查目的地、發文身分、受眾、附件與立即發布選項。個人貼文與社團貼文的操作可能不同，逐處確認。
4. 若出現額外分享到限時動態的設定，確認使用者是否要分享。若關閉會影響未來貼文，明確說明影響後詢問，依回答操作。付費推廣只有明確要求才啟用。
5. 發布後在該目的地核實文案與附件出現，開啟時間戳記取得獨立貼文網址。介面顯示待審核時記錄待審核。結果不明先查頁面，再決定是否重試。
6. 將每處貼文網址、實際發布／待審狀態及限時動態選擇寫入影片專案的 Facebook發布結果.md。可取得時保存可辨識目的地與貼文的截圖。

僅在使用者明確指定或本次已授權時跨貼到多個目的地。社群發布失敗時保留已成功的其他貼文，按目的地續做。
