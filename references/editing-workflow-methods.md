# 剪輯工作流銜接

本文件將剪輯相關工作從企劃技能接到獨立的 `video-editing-workflow/SKILL.md`。三份來源逐字稿的時間碼與限制見 [three-video-editing-analysis.md](three-video-editing-analysis.md)。本文件記錄可重用方法；外部平台功能須在使用當下核對。

## 何時交給剪輯技能

當任務包含大量實拍素材、AI 協助整理鏡頭或編排時間軸、DaVinci Resolve 後製、Remotion 或其他程式動畫段落、生成式影片鏡頭拼接，或需要完整剪輯驗收時，讀取 `video-editing-workflow/SKILL.md`。純腳本、企劃、分鏡或既有產生器可完成的圖卡影片，仍由本技能處理；需要時只引用剪輯技能的相關檢查表。

## 共用交接契約

剪輯前，由企劃技能提供下列資料；缺少時先從現有專案資料整理，不要重問使用者已提供的內容：

1. 影片目的、觀眾成果、頻道與成片長度／比例。
2. 核定旁白及逐句 ID、字幕需求、章節和故事節拍。
3. 分鏡鏡號、畫面目的、實拍／動畫／錄屏來源，以及必須保留的證據。
4. 素材 manifest：來源、路徑、片段時間碼、授權、角色／場景 ID、狀態和已知問題。
5. 固定品牌設定、配音、配樂、片頭片尾與浮水印路徑；依 `fixed-settings.md`、頻道 profile 和資產核定狀態執行。
6. 交付格式、檔名和品質報告要求。

## 剪輯流程增補

| 階段 | 工作 | 必須留下的檢查證據 |
|---|---|---|
| 素材盤點 | 讀取檔名／中繼資料；建立縮圖聯絡表或可定位的片段索引；保留原始路徑 | 每個候選鏡頭可回到來源檔與時間碼；不把縮圖推測當內容事實 |
| 故事與鏡頭 | 按旁白、事件和分鏡順序挑鏡頭；註明保留、待審、排除和理由 | 每個剪點有用途；證據鏡頭、人物方向、動作和場景接得上 |
| 粗剪 | AI 可整理候選、產生時間軸草案、套版或提出節奏建議 | 不覆蓋來源；保存可還原專案；人工核對抖動、失焦、重複、錯誤或誤導畫面 |
| 動畫／生成片段 | 以角色表、場景圖、資產 ID、鏡頭表及連戲限制生成短段，先看代表段再批次 | 臉、服裝、道具、方向、光線、字幕安全區；生成缺陷不靠轉場掩蓋 |
| 混剪與聲音 | 合成實拍、真實錄屏、動畫與旁白；音效與配樂放在有敘事用途的位置 | 旁白可懂、音效不蓋語音、轉場不造成誤解、片頭片尾品牌正確 |
| 驗收輸出 | 依實際成片全片播放或分段逐鏡核查；檢查解析度、比例、字幕、音訊、片尾和檔案 | 留下修正表及最終檔路徑；不可只依渲染成功或 AI 摘要判定品質 |

## AI 剪輯任務提示欄位

給剪輯代理／MCP 的工作單要描述：

- **成果**：觀眾、平台、比例、目標長度、要傳達的核心結果。
- **敘事順序**：開場鉤子、必要證據、操作步驟、轉折／結果、收尾；鏡號與旁白句 ID 對應。
- **素材規則**：素材根目錄、檔案用途、可用範圍；禁止猜測來源內容或捏造 UI／實測結果。
- **剪輯判準**：首選／備選／禁止鏡頭，節奏，必要上下文，需保留的錯誤／限制揭露。
- **視聽要求**：字幕、標註、轉場、色彩、音效、配樂 ducking、品牌位置。
- **輸出與回報**：非破壞性專案或時間軸草案、預覽、缺件、逐項人工複核點和預定輸出規格。

不得只用「剪得電影感一點」「自動挑最好鏡頭」等無法核對的說法。若 AI 有剪輯專案寫入權限，先使用複本／新時間軸，匯出前回放成片；工具的 MCP 安裝來源、權限和可執行操作依官方說明及當前環境檢查。

## Remotion、build.py 與時間軸剪輯的分工

- Remotion 等程式化工具適用於樣式固定、需要重複渲染的圖卡、字幕動畫、資訊視覺化和一致版型；輸出明確的片段、比例、fps、透明／背景規格及音訊需求。
- 現有 `build.py` 依 `references/build-pipeline.md` 可處理其支援的 YAML、圖卡和動畫。此文件不代表 build.py 已能讀取 Remotion、Resolve 專案或 MCP 輸出。
- DaVinci Resolve 等 NLE 適用於挑鏡、聲畫同步、實拍與生成段混剪、音效／配樂及最終輸出。由 AI 提議的時間軸先當草稿，人工確認剪點與敘事後再交付。
- 一個單集可採用不同工具，但需有明確中間格式與所有來源素材的可追溯 ID；不為追求工具數量增加無必要轉檔。

## 品質閘門

1. **敘事**：每段都推進觀眾問題；必要的原因、步驟、結果沒有被快剪刪掉。
2. **連戲**：人物身份、服裝、道具、動作方向、視線、位置和光線沒有無故跳變。
3. **實證**：實測、UI、數字、前後比較均能回到真實來源；示意動畫清楚標示。
4. **節奏**：每鏡頭有敘事目的，景別與停留時間服務資訊和情緒，不因 AI 快速輸出而忽略重複或空鏡。
5. **聲音**：逐句旁白完整，剪接不切斷語意；音樂／音效服從旁白與品牌設定。
6. **成品**：全片檢查黑格、閃格、穿幫、字幕、遮擋、音訊跳變、片頭片尾和輸出格式。

這些方法取自字幕示範並依本技能的核定品牌、來源追溯和驗收規則調整；不構成工具效能比較或剪輯品質保證。
