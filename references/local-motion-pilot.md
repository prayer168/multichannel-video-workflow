# 本機動態試片、畫面細修與交接

適用於已有腳本或分鏡、要求本機試產一段可播放的解說動畫，或要求細修既有試片。依原先選定的頻道、美術與交付規格製作，沿用配音與字幕規則。試片特別指定的暫配音或內嵌字幕只適用該試片。

## 製作與畫面審查

1. 先鎖定腳本、鏡號、旁白素材與輸出規格。把關鍵詞及其畫面動作列成對時表，並保留等待觀眾思考的時間。按旁白實際音訊對時，記錄依據是語音辨識、音素時間或人工校準。自動轉寫的近音誤辨列入試聽，不能當成人工驗收結果。
2. 選取代表畫格及關鍵動作前後的畫格審查。遇到「畫面不夠細緻」時，依畫面功能加強主體辨識、構圖層次、材質、光影與有意義的動態。檢查標示、字幕和主體在播放尺寸的清晰度。科學圖解標註比例或示意範圍，量化圖表標明單位與來源，地形示意不填入虛構實測值。
3. 單純細修畫面時，沿用已核定的旁白、字幕和預定對時。把不同版本另存，並交付可播放的修訂版及可用來對照的代表畫格。若需求涉及正式成片，依原有動態圖文停點及交付規則驗收。

## 重現與局部重渲染

- 記錄實際作業系統、工具版本、依賴和素材路徑。使用者指定 Script2Film 時，先核對該版本安裝文件、環境診斷與範例。若指定平台不可用，記錄未測範圍及實際錯誤。可用標示清楚的本機替代方案交付試片，原生場景草稿、格式檢查和原生實跑各自據實標示。
- 保存可編輯場景、素材、旁白、字幕與場景時間。引擎支援分段時，只重渲染變更的段落；共用畫面、素材或時間軸受影響時，重渲染所有依賴段落。
- 驗收可暫改一項局部樣式再復原。比對未改段落及 SRT，並在重新封裝後比對解碼音軌。採用二進位雜湊或逐幀／逐樣本比對，依引擎可重現性記錄結果。確認片長、解析度、可完整解碼及關鍵畫格；記下實測全片／局部耗時和人工修正時數，只記有實際量測的數值。

## 成片後的代理交接

沿用 [素材白名單與 ZIP 驗證](animation-handoff.md)。包內包含目前 MP4、SRT、現有旁白、可重渲染的場景及程式、必要素材、代表畫格與紀錄。入口文件寫清楚從哪個版本續作、依賴、全片／局部指令與待驗證項目。交給 Claude Code 時在專案根目錄放 `CLAUDE.md`；若無可用的接收環境，就交付經驗證的 ZIP 供載入。交接包按授權處理素材，產出交接包不包含平台發布。
