# 04 剪輯規範

## 時間軸軌道配置
```
V5  標註層：網址標籤 / TIP 角標 / 箭頭 / 提示詞卡
V3  插畫 / B-roll / 標題卡
V2  螢幕錄影（已推拉）
V1  片頭（黑熊老師品牌片頭，含品牌音樂，無人聲）
A1  旁白（主）
A2  BGM（自動 ducking，-18 至 -24 dB）
A3  音效（pop / whoosh）
```

## 剪輯步驟
1. 先放旁白，**以聲音為主軸**
2. 把錄影對齊旁白：旁白講到「點擊」時，畫面剛好點下去
3. 剪掉所有等待（旁白「過了一會兒」處直接跳到成果）
4. 推拉：操作前推近（×1.8–2.2），操作後拉回；緩動 ease-in-out 0.6 秒
5. 加標註：
   - 網址標籤：右下角圓角矩形，品牌色底、白字，停留 3–5 秒，淡入加輕微上移
   - TIP 角標：右下角，深色半透明底，左側藍色直線，停留 5 秒
   - 紅箭頭或圈選：指向小按鈕
6. 加插畫與 B-roll：開場蒙太奇、概念段落、章節轉換
7. 檢查「40 秒法則」：任何 40 秒內一定要有推拉、標註或換畫面其中之一
8. 音樂：只用免費、非商用授權的柔和 BGM（見 01_風格分析報告/08），全程循環，開場較大聲，旁白進來後自動壓低；把曲名、來源、授權記錄到專案資料夾
9. 片頭：放上 `04_品牌資產/片頭動畫/黑熊老師片頭_4s.mp4`（片頭音訊：`04_品牌資產/配樂音效/片頭音訊_定案_M1＋粉筆_4秒.wav`）；主講旁白在片頭結束後才開始（片頭有自己的品牌音樂，不要重疊）；BGM 在片頭結束時淡入
10. 片尾：「拜拜」之後保留 1–2 秒，再淡出

## 禁忌
- ❌ 花俏轉場（翻頁、旋轉、閃白）
- ❌ 燒錄大字幕（字幕用 CC 上傳）
- ❌ 搞笑音效
- ❌ 訂閱按讚動畫

# 05 字幕規範

- 格式：SRT，以 CC 字幕方式上傳 YouTube（語言設為 zh-TW），**不燒錄在畫面上**
- 每行一句，約 12–13 字，**不加句尾標點**（逗號、句號都不加，保留問號與引號）
- 英文專有名詞保留原文，中英之間加半形空格：「Claude Design 自從推出之後」
- 括號補充中文：「Effort (努力)」
- 製作方式：因為腳本本身就是一行一句，直接用腳本搭配音檔做強制對齊（剪映「文稿匹配」、Whisper、aeneas）
- **同步產生英文逐字稿與英文字幕（必做）**：
  1. 腳本定稿時，使用 `07_仿真提示詞/08_英文逐字稿提示詞.md` A 段產生「中英對照逐字稿」（一行對一行，行數相同）
  2. 中文 SRT 完成後，使用 B 段產生英文 SRT（時間碼完全沿用中文版）
  3. 英文每行 ≤ 42 字元；UI 名稱使用軟體的英文原始介面名稱
  4. 檔名：`字幕_zh-TW.srt`、`字幕_en.srt`，存放在 `專案/2_製作中/字幕/`
  5. 另外輸出純文字的 `英文逐字稿.txt` 到 `專案/3_製作後/`
- 上傳 YouTube 時，zh-TW 與 en 兩種 CC 字幕都要上傳
