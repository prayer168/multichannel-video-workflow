# 多頻道製作範本

資料夾、正式 MP4 時戳、四區段 `上架文案.txt` 及獨立最終逐字稿，依 [project-layout.md](project-layout.md)；本檔其他欄位是內容範本，舊路徑不作為正式交付結構。

先讀取 `channel-routing.md` 與所選 `../profiles/` 設定檔。下列欄位依本集需求填寫；英文素材、SEO、螢幕錄影與 TTS 是條件式產出。

## 專案卡

| 欄位 | 內容 |
|---|---|
| 主題／頻道 ID／頻道名稱 | blackbear-science 或 ai-watch（擇一） |
| 主要觀眾／觀看情境／先備知識 | 自然教室另記年級、課程與學習目標 |
| 觀眾問題／影片承諾 | 看完能理解或完成什麼；列出必要條件 |
| 可檢查成果 | 觀察證據、教材、操作結果或作品 |
| 敘事方式／目標時長 | 依內容與實際配音估計；不固定字數或句長 |
| 來源與查證日期 | 主張、來源連結、版本、發布日期、查證日期、待確認事項 |
| 片頭／片頭音訊／片尾 | 記錄核定路徑、頻道歸屬、檔案存在檢查與狀態 |
| 浮水印／BGM／聲線／CTA | 僅使用本頻道核定識別；記錄授權 |
| 字幕／英文需求 | 語言、逐字稿、字幕、上架及社群英文是否需要 |
| 預計上架日／素材缺口 | 缺少片尾或品牌影音時列待提供／待建立 |

素材是外部資產，不在 repo；製作器欄位與路徑解析見 `build-pipeline.md`。專案卡的片尾欄位不是程式支援的 YAML key。

## 指令碼（02_指令碼.md）

1. 頻道片頭：引用本頻道核定素材；缺少時寫待建立，不填假路徑。
2. 開場：依頻道招呼，以生活、工作或教學情境提出問題，交代承諾與可見成果。
3. 概念：新術語先白話／例子，再補正式名稱與用途。
4. 案例與示範：交代材料／環境、步驟、觀察或操作結果、證據、限制。實驗另列安全事項；開發另列版本、授權、安裝、環境變數與安全性。
5. 成果與回顧：展示觀眾看得見的成果，分清實測、官方宣稱、示意和推論。
6. 結尾：本頻道 CTA 與核定片尾；缺少影音時列入待提供清單。旁白結語不能代替核定片尾。

分場旁白使用 `## S01 標題`、一行一句以配合生成器；句長、語速和段落口頭禪依受眾與配音調整。註解、來源及分鏡標記放在企劃稿，不混進供 TTS 讀取的旁白稿。

自我檢查：情境、承諾、術語解釋、成果、查證與限制是否完整？標題的每項數字是否有量測方式與條件？品牌與 CTA 是否只屬於本頻道？

## 標題、縮圖與上架文案

- 標題候選：自然教室「月亮每天長得一樣嗎？一起記錄月相」；AI Watch「用開源工具做一個待辦 App：安裝、實測與限制」。
- 縮圖呈現本集問題或真實成果；使用本頻道核定色彩和素材，未核定時交付無品牌草稿。手機大小仍須清楚。
- 上架文案：摘要、章節與時間碼、查證來源／版本／限制、適用年級或環境、素材授權、本頻道相關連結、Hashtag、置頂問題。支援／會員／提示詞連結僅在確實存在時加入。
- 英文標題、說明、逐字稿與字幕按需求產生。對照翻譯保留句子 ID 和時間碼，顯示行長以可讀性調整，不刪掉必要資訊來硬湊字數。
- `scripts/md2txt.py` 保留 .md 原稿並輸出上架 .txt、YouTube標記.txt、置頂留言.txt。

## 生活化動畫與實測素材包

角色表：

| 角色 ID | 外觀與服裝 | 參考圖路徑與核定狀態 | 敘事功能 | 動作與禁忌 |
|---|---|---|---|---|
| 主持人 | 沿用 fixed-settings 核定黑熊 | 核定素材實際路徑 | 提問與驗收 | 不自行換造型 |
| 配角 | 本集原創設定 | 草稿或核定路徑 | 比喻／反應／指出缺件 | 不冒充官方吉祥物 |

動畫素材表：

| 素材 ID／鏡號 | 比喻與邊界 | 角色與背景 | 動作／鏡頭／時長 | 生成提示詞 | 後製文字與狀態 |
|---|---|---|---|---|---|
| A01／S01 | 對應概念；不能推導什麼 | 沿用參考設定 | 約 5–8 秒短片 | 共用設定＋個別場景 | 文字後製；待生成 |

實測分支：每關先寫透過條件、輸入快照、需要儲存的證據，再寫成功／部分成功／失敗口播。配音稿只選符合證據的一支。

| 關卡 | 透過條件 | 證據／來源／環境 | 經過時間／人工時間 | 修正次數／確認次數 | 結果與所選分支 |
|---|---|---|---|---|---|
| 第一關 | 可檢查的行為或成果 | 版本與檔名 | 待填 | 待填 | 待測 |

製作包 README 範本：

```text
影片：〔主題〕；頻道：〔channel_id〕；長度：〔目標〕；規格：〔比例與解析度〕。
內容：指令碼、分鏡、角色表、動畫提示詞、已有參考圖、實測與驗收資料。
使用：解壓 → 在 Claude Code／Codex 開啟 → 讀 START_HERE.md → 先做時間軸與缺件清單 → 製作預覽 → 驗收。
固定設定：列出本集核定片頭、角色、聲線、配樂與片尾；按素材存在狀態記錄，不能只寫假路徑。
缺件：哪些素材尚未產生、哪些結果尚未測得；待補不等於已完成。
```

START_HERE 範本：

```text
請先讀本包 README、指令碼、分鏡、角色表、動畫提示詞、圖片與實測驗收表。
已安裝 multichannel-video-workflow 時，先讀其 fixed-settings、頻道 profile、build-pipeline 與 animation-handoff；未安裝時讀包內對應的必要設定摘要。
盤點環境與素材，建立按鏡號排列的時間軸及缺件清單。沿用本集核定品牌、聲線和配樂，動畫以角色參考維持一致。
只能用真實錄屏表示軟體操作，不能生成假 UI 或虛構成功；旁白分支依證據選擇。
優先用現有建置流程製作預覽，不為增加動畫而改寫整套影片引擎。
沒有可用配音或影片生成能力時，保留 timing／無配音預覽與待補清單，不擅自改用其他聲線或購買服務。
交付可檢查預覽、剪輯專案或原始碼、素材索引與具體缺件；未授權不部署、不發文、不上傳 YouTube。
```

素材清單格式與打包指令見 `animation-handoff.md`。最終包須包含 README、START_HERE、BUNDLE_MANIFEST、MISSING_ASSETS，逐項核對實際內容；影象預覽不等於完成動畫。
