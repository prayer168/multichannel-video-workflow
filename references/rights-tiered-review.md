# 素材權利分級預審（2.42.0）

2026-11-25《尼莫點》定案：逐項人工審查太耗時（34 項待審）。改成**下載時就登記、成片後自動預審、只把例外交給使用者**。使用者授權：自動預審判為 T0／T1 的素材可由程式標為 APPROVED（審查者欄寫「自動預審（分級規則 v1，使用者授權）」），T2 才由使用者決定。

## 一、三級規則

| 級別 | 條件 | 處理 |
|---|---|---|
| **T0 免審** | 自有原創（配音、配樂、熊掌、原創動畫、字型授權）；美國聯邦機構（NASA、NOAA、USGS…）公有領域，且無任何旗標 | 自動 APPROVED |
| **T1 自動通過** | CC0／CC BY（非 SA）且原頁重查相符、CC BY 署名已在 `CREDITS.md`；1900 年前的公有領域作品；公有領域資料集白名單（Natural Earth） | 自動 APPROVED |
| **T2 人工** | 任一旗標：檔案指紋不符、原頁查不到或授權不符、畫面有可辨識人物（文字線索或人臉偵測）、標誌／商標、NASA 說明提到第三方機構或 ©、非政府作者標公有領域（含「作者不是政府、只是收在政府圖庫」）、AI 生成圖、無原檔的總括紀錄 | 列入例外清單，附建議，使用者回覆核可／不核可 |

## 二、工具

```bash
python scripts/build/rights_precheck.py --audit <專案>/output/rights_audit.csv \
  --sources <專案>/assets/licensed/sources.json --licensed <專案>/assets/licensed \
  --report <交付根目錄>/權利預審報告.md [--apply]
```

- 先不加 `--apply` 試跑看報告，再加 `--apply` 寫回（自動備份 `.bak_時間`）。只處理 `decision=HOLD` 的列；已核可或撤回的不動，可重複執行。
- 人臉偵測需要 `opencv-python-headless<5`（OpenCV 5 移除了 `CascadeClassifier`）；沒有時只靠文字旗標，報告會註明。
- 門檻（`minNeighbors=10`、最小臉 = 短邊 4%）依《尼莫點》實測：太鬆會把太空站、矽藻、船首浪花當成臉；仍可能有少量誤判，例外清單要寫明「誤判」並建議核可。
- Wikimedia Commons 會限流（429），工具已內建退避重試；仍失敗的列不會自動通過。

## 三、例外清單的寫法（交給使用者）

在交付根目錄寫 `權利審查清單.md`：一表列出 T2 每一項的「素材（用在哪幾鏡）／為什麼需要人看／我的建議」。建議要具體：看過成片是否真的出現標誌或人臉、是否誤判、可用的替代素材。使用者逐項回覆後，把審查者寫成使用者姓名、填日期與一句理由，再拿掉「Stage D 先導・非正式成片」重新輸出。

## 四、從源頭減少 T2（選素材時就做）

1. **白名單優先**：NASA／NOAA／USGS 公有領域、CC0；CC BY 次之（記得署名）；不用 CC BY-SA、NC、ND。
2. **避開會變 T2 的畫面**：可辨識的近景人臉、機構或商業標誌、贊助商看板；必要時下載後就裁切，並在 `sources.json` 的 `modifications` 寫明。
3. **注意「政府圖庫裡的非政府作者」**：NOAA、NASA 圖庫偶有大學或外部攝影師的作品，作者欄不是聯邦員工就當 T2。
4. **能用真實資料畫，就不用照片**：地圖、軌道、距離、衛星資料（如 NASA PACE 葉綠素）以程式繪製，版權屬頻道，幾乎不必審。
5. **下載當下就登記**：檔案 SHA-256、原頁網址、作者、授權、用途、裁切方式寫入 `assets/licensed/sources.json`、`CREDITS.md`、`rights_audit.csv`（CSV 欄位含逗號時要加引號，網址常有逗號）。
