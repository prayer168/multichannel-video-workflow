# 旁白驅動畫面設計

本文件補充「旁白定稿後，畫面如何隨講解跑動」的方法。用途是把每句旁白轉成觀眾看得懂的視覺事件，不是替每句加一個無關的裝飾動畫。這些規則綜合公開影片可觀察的敘事方法與本技能的聲畫對齊、實證、品牌及驗收要求；不複製任何頻道的台詞、品牌、素材或獨特視覺。

## 核心原則

1. **先聽懂，再選畫面。** 逐句標出這句在做什麼：提出問題、解釋因果、比較、示範步驟、展示證據、揭露限制、轉折或總結。畫面必須對應這個語意功能。
2. **旁白是時間骨架。** 先定稿旁白並切出語意氣口，再安排動作起點、重點落點、停留與轉場。修改旁白後，重新核對字幕時間、動作同步與前後鏡頭。
3. **每個氣口只設一個主視覺動作。** 例如物件進場、鏡頭推近、元素拆解、路徑連線、對照切換、狀態改變或成果展開。次要細節可延續，但不可同時搶焦。
4. **動作要把意思演出來。** 「逐步增加」就讓數量逐步增加；「比較」就建立並列或切換；「原因造成結果」就展示可追蹤的因果路徑；「先做 A 再做 B」就讓 A 完成後才引出 B。避免每句一律淡入淡出、滑入卡片或無理由縮放。
5. **全片維持一套視覺語法，鏡頭表現可以變化。** 統一字體、色彩、材質、光線、線條、圖表規則與轉場邏輯；在這套風格內輪替近景／遠景、平移／推拉、圖解／實拍／UI／角色演出，讓影片有變化但不割裂。
6. **先讓觀眾看清楚。** 新概念先給整體，再拆局部；重要標籤與數字有足夠停留時間；旁白說到關鍵詞時才標示或強調，不讓裝飾搶過資訊。
7. **真實與示意要分清。** 真實 UI、操作、實驗結果與數據使用可追溯的錄屏或來源；示意動畫要標示為示意，不能假裝成實測。任何外部素材保留來源與授權資訊。
8. **聲畫同步採語意同步。** 不要求每個字都跳動；在句子的關鍵詞、因果轉折、數字、操作完成或結論處對齊視覺變化。語速快時簡化畫面，停頓時讓重點停留。
9. **節奏由資訊密度決定。** 操作和推理需要觀眾讀取時放慢；重複或已理解內容可加快或摘要；重大結果前保留期待，結果出現後留足確認時間。40 秒只作節奏檢視參考，不是硬切規則。
10. **做出代表段再擴充。** 先挑一段含概念、動作、標註與轉場的旁白，製作代表鏡頭或靜幀條；人工確認可讀性、節奏、風格和字幕安全區後再批次延伸。

## 旁白到畫面的映射表

分鏡表增加「旁白功能」「主視覺動詞」「關鍵詞落點」「畫面停留理由」欄，逐句記錄：

| 旁白句 ID／氣口 | 旁白功能 | 主視覺與動作 | 關鍵詞落點 | 畫面來源／證據 | 停留與轉場 |
|---|---|---|---|---|---|
| N01 | 提出問題 | 兩個結果先後出現，鏡頭停在矛盾處 | 問句最後一詞 | 示意圖 | 留白一拍後推近 |
| N02 | 解釋因果 | 由原因沿箭頭推進到結果，相關部件逐一亮起 | 因果連接詞 | 查證後的圖解 | 結果完整呈現後再切 |
| N03 | 示範操作 | 真實 UI 錄屏，游標只做旁白所述操作 | 按鈕名稱／完成狀態 | 原始錄屏 | 操作完成後停留確認 |

表格內容依主題改寫，以上只是欄位示意，不是固定鏡頭模板。畫面以目的為先，可使用實拍、螢幕錄影、程式動畫、資訊圖表、角色演出或經授權素材。

## 旁白功能與可用畫面動詞

| 旁白功能 | 可考慮的畫面動詞 | 常見錯誤 |
|---|---|---|
| 問題／懸念 | 顯示矛盾、遮住答案、推近線索、留下空位 | 開場先塞一整頁文字 |
| 定義／介紹 | 先呈現整體，再圈選名稱與部件 | 同時放太多術語和箭頭 |
| 因果／流程 | 連接、流動、依序點亮、狀態轉換 | 箭頭方向或前後順序錯誤 |
| 比較／差異 | 並列、對齊尺度、切換同一變因、差異高亮 | 尺度不同卻暗示公平比較 |
| 操作教學 | 真 UI、局部放大、游標指向、完成狀態停留 | 虛構 UI 或游標遮住關鍵字 |
| 數據／證據 | 數值逐步形成、圖表標出來源與單位 | 無來源數字或誤導比例 |
| 轉折／發現 | 畫面重組、視角轉換、前述線索匯合 | 為戲劇化添加旁白沒有支持的事實 |
| 總結／回扣 | 元素收斂成答案、回到開場構圖、成果完整展示 | 只放口號或新增未解釋資訊 |

## 可直接複製的動畫／剪輯交接提示詞

```text
請依據已定稿的旁白與分鏡，設計一支由旁白語意帶動畫面的解說影片。目標是讓觀眾一邊聽旁白、一邊看見概念、操作或因果如何發生；不要只替旁白加裝飾，也不要照抄任何參考影片的台詞、品牌、畫面素材或獨特視覺。

開始前先讀取本專案的頻道設定、fixed-settings、字幕規格、品牌資產狀態，以及適用的 ui-narration-animation／motion-explainer-workflow 規則。遵守本頻道核定的角色、片頭片尾、聲線、配樂和色彩；缺少核定素材時標記缺件，不自行仿造品牌。

輸入資料：
- 影片目的／觀眾成果：{填寫}
- 頻道、比例、解析度、幀率與目標長度：{填寫}
- 核定旁白及逐句 ID／時間碼：{貼上}
- 章節與故事節拍：{貼上}
- 已有素材及路徑、來源、授權、素材 ID：{列出}
- 核定視覺風格與限制：{填寫}
- 真實 UI／數據／操作的證據來源：{列出}

工作方式：
1. 逐句辨認旁白功能（提問、定義、因果、比較、操作、證據、轉折、限制、總結），先輸出「旁白句 ID → 功能 → 畫面目的」對照表。
2. 將旁白按語意氣口切段；每段指定一個主視覺動作，用清楚的動詞描述（例如展開、連接、拆解、流動、對照、推近、停留、收斂）。避免每句重複同一種卡片進場或轉場。
3. 依旁白的關鍵詞、因果連接詞、數字、操作完成點安排動畫起始、落點與停留。不要為了逐字跳動而犧牲可讀性；讓字幕停頓與旁白一致。
4. 建立全片一致的字體、色彩、材質、光線、標註和轉場語法；在一致風格內有節奏地變換景別、構圖與媒材。每個鏡頭都要推進觀眾理解或情緒。
5. 概念解說採整體到局部；比較使用相同尺度與基準；流程和因果保留正確順序；真實操作使用可追溯錄屏。不得捏造 UI、數據、實測結果、人物動作或來源內容。示意畫面明確標示「示意」。
6. 音效只在有敘事功能且不遮蔽旁白時使用；配樂依頻道設定 ducking。重要資訊避開字幕安全區 y=880–1000（1920×1080 座標）。
7. 先選一段代表性旁白製作預覽或靜幀條，列出預計時長、關鍵動作、字幕位置、素材來源及待確認事項；人工核准代表段後再延伸全片。若使用者已授權完整製作，按其指示完成，不額外停在流程確認。
8. 最後提供逐句對齊表、鏡頭表、素材清單與來源、缺件、示意／實證標記、字幕與音訊檢查點。輸出後回放影片，逐鏡核對語意、同步、可讀性、連戲、字幕安全區及黑格／閃格。

每個鏡頭請輸出：鏡號｜旁白句 ID／時間碼｜旁白功能｜畫面目的｜構圖與素材｜主視覺動作｜關鍵詞落點｜鏡頭運動｜標註／字幕安全｜音效／配樂｜來源與證據｜轉場｜預估時長｜驗收方式。

判斷準則：如果靜音看畫面仍無法理解這一鏡要表達的關係，補足構圖或標註；如果只聽旁白而畫面沒有提供理解線索，重做該鏡；如果移除某個動畫完全不影響理解，也不增加情緒或注意力，就刪除該動畫。
```
