# YouTube SEO 規範

> 目的：讓影片**被搜尋到、被推薦到**，進而增加觀看。
> 教學影片的搜尋流量占比高，而且有長尾效應（一支好的教學片能被搜尋好幾年），所以 SEO 的投資報酬率很高。

## 〇、先搞懂 SEO 的角色
YouTube 決定要不要推薦你的影片，主要看三件事：
1. **點閱率（CTR）**：看到縮圖和標題後，有多少人點進來
2. **觀看時長與留存**：點進來後看了多久
3. **觀眾滿意度**：看完之後的互動、有沒有繼續看下一支

SEO（標題、說明欄、字幕、章節、標籤）的作用，是讓 YouTube 和 Google **理解影片在講什麼、該出現在哪些搜尋結果**。
→ SEO 負責「被找到」，內容品質負責「被留住」，兩者缺一不可。

| 項目 | 影響程度 | 備註 |
|------|---------|------|
| 標題 | ★★★★★ | 同時影響搜尋排名與點閱率 |
| 縮圖 | ★★★★★ | 主要影響點閱率 |
| 說明欄前 2 行 | ★★★★ | 顯示在搜尋結果中 |
| 字幕（CC） | ★★★★ | 會被收錄；英文字幕能觸及英文搜尋 |
| 章節 | ★★★ | Google 搜尋會出現「重要時刻」 |
| Hashtag | ★★ | 前 3 個會顯示在標題上方 |
| 標籤（tags） | ★ | 只用來補錯字與同義詞 |

## 一、選題階段：搜尋需求檢查
在選題雷達推薦前 3 名之後、選題評估之前執行。

1. 執行：
   ```bash
   python scripts/seo_keywords.py "工具名" --top 20 --dates --out 1_製作前/05_SEO關鍵字研究.md
   ```
2. 閱讀報告：
   - **搜尋建議（需求）**：與工具名直接相關的建議詞有幾個？有沒有「教學、中文、安裝、免費」這類新手詞？
   - **競爭分析（供給）**：前 20 名中，繁中影片有幾支？近 90 天有幾支？觀看數中位數多少？
   - **機會判斷**：🟢 高 / 🟡 中 / ⚪ 需求低（改走推薦流量）/ 🔴 競爭高
3. 選出**主要關鍵字 1 個＋次要關鍵字 3–5 個**（從建議詞中挑選，用觀眾的原始寫法）
4. 若判斷為 🔴，就要在選題評估中寫出**差異化角度**（新版本、新手向、組合技、在地化），否則換題

## 二、腳本階段：自然融入關鍵字
- 開場 30 秒內，旁白要**唸出主要關鍵字**（字幕會被收錄，而且 YouTube 會分析語音）
- 章節開頭的第一句，自然地提到該章節的關鍵字
- 不要硬塞關鍵字，旁白必須保持 Papaya 的自然口語

## 三、上架階段：SEO 版的標題、說明欄、章節

### 1. 標題（保留 Papaya 鉤子句型＋關鍵字前移）
- **主要關鍵字必須出現在前 40 字內**（手機搜尋結果大約只顯示 40–50 字）
- 結構調整：`【工具名／主要關鍵字】＋鉤子＋好處`，或 `鉤子（很短）＋主要關鍵字＋好處`
- 例子：
  - ❌ 還在用 PPT 製作廉價簡報動畫？Claude Design 2.0 迎來重大升級…（關鍵字在第 16 字，可以接受）
  - ✅ Claude Skills 教學｜我用一個技能省下所有生圖訂閱費！每月現省上千元
- 使用觀眾的寫法（例如搜尋建議是「claude skills 教學」，標題就寫「Claude Skills 教學」）
- 總長度維持 40–60 字，不要只為了 SEO 而拉長

### 2. 說明欄（**和 Papaya 不同：開頭加摘要**）
```
{第 1–2 句：含主要關鍵字與次要關鍵字的摘要，150 字以內；這兩行會出現在搜尋結果}

🔹 內容綱要
00:00 {含關鍵字的章節名稱}
…
🔹 提示詞連結 / 🔹 網站連結 / 🔹 支持 / 🔹 會員目錄

#主要關鍵字 #次要關鍵字 #教學
```
- 摘要寫成自然的句子，不要堆疊關鍵字
- 例子：「這支 Claude Skills 教學會帶你從零建立一個生圖技能，串接 FAL API，用很低的成本生成圖片和影片，完全不用訂閱 Midjourney。」

### 3. 章節名稱
- 用觀眾會搜尋的詞：「建立技能」→「Claude Skills 建立技能」、「取得金鑰」→「FAL API 金鑰申請」
- 第一個章節是 00:00，至少 3 個，每個 ≥ 10 秒
- 章節名稱會出現在 Google 搜尋的「重要時刻」

### 4. Hashtag（3–5 個）
- 前 3 個會顯示在標題上方，所以依重要性排序：`#主要關鍵字 #工具名 #教學`
- 超過 15 個會被 YouTube 忽略，所以要精簡

### 5. 標籤（tags，影響小，但要填）
- 主要關鍵字、次要關鍵字、工具名的各種寫法（英文、中文、簡體如「claude教程」、常見錯字如「cloud skills」）
- 總長度在 500 字元以內

### 6. 字幕
- zh-TW 與 en 兩種 CC 字幕都要上傳（已經在技能 v1.1.0 中）
- 英文標題與英文說明欄也要翻譯（Studio →「語言」→ 標題與說明），讓英文搜尋也找得到

## 四、發布階段：導流設定
| 項目 | 做法 |
|------|------|
| 播放清單 | 依主題建立系列（例如「Claude 系列」「免費開源神器」「Notion 教學」）；播放清單標題也要含關鍵字 |
| 結束畫面 | 最後 5–20 秒，推薦 1 支最相關的影片＋訂閱按鈕（畫面保持簡潔，不喊訂閱） |
| 資訊卡 | 在旁白提到其他工具或前一支影片時插入 |
| 置頂留言 | 重點摘要＋提示詞連結＋一個問題，引導觀眾留言 |
| 社群貼文 | 發布當天貼一則，附上縮圖和一句好處 |

## 五、發布後：優化迴圈
| 時間 | 檢查 | 行動 |
|------|------|------|
| 48 小時 | 點閱率（CTR）、前 30 秒留存 | 點閱率 < 4% → 用 YouTube 工作室的「測試與比較」測試 2–3 張縮圖（能不能同時測標題，以你的 Studio 為準） |
| 7 天 | 流量來源：YouTube 搜尋、推薦、外部 | 搜尋占比低 → 檢查標題和說明欄的關鍵字 |
| 7 天 | 「YouTube 搜尋字詞」報表 | 觀眾實際搜尋的詞與標題不同 → 修改標題、說明欄、標籤 |
| 28 天 | 觀看時長、訂閱轉換 | 把有效的關鍵字與標題寫法記錄到選題庫與技能 |

## 六、禁止事項
- ❌ 關鍵字堆疊（標題或說明欄重複同一個詞很多次）
- ❌ 誤導性標題或縮圖（內容做不到標題承諾的事）→ 留存差，反而被降低推薦
- ❌ 在標籤中放不相關的熱門詞
- ❌ 為了 SEO 犧牲旁白的自然口語
