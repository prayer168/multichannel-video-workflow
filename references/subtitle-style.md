# 嵌入字幕樣式與字幕安全區（2.10.0 固定設定）

2026-10-21 使用者定案（《Nano Banana 2.1 做教材插圖》製作時逐步確認）。兩個頻道的正式影片都照做；要改數值先問使用者。

## 一、樣式（橫式主片 1920×1080）

| 項目 | 固定值 |
|---|---|
| 行數 | **一次只出現一行**，不出現兩行字幕 |
| 每行字數 | ≤ 17 字（英數字以 0.55 字計）；17 字約 990 px 寬，置中時碰不到右下角黑熊老師（x ≥ 1552） |
| 位置 | **水平置中**；文字底部離畫面下緣 **96 px**（約 y 984）。不貼底，避開 YouTube 播放列與進度條 |
| 字型 | 微軟正黑體粗體（Windows：Microsoft JhengHei）；雲端用 Noto Sans CJK TC Bold |
| 大小 | 58（1080p） |
| 顏色 | **白字＋黑框**：外框 4.5 px 黑色、陰影 1.5 px（約 60% 黑）；**不加底色框** |
| 標點 | 句尾的「，、。；：」去掉；句中的「，；」改成全形空白；頓號、引號「」、問號、驚嘆號保留 |

ASS 樣式列（`scripts/build/subs_oneline.py` 內建，PlayRes 1920×1080）：

```
Style: Default,Microsoft JhengHei,58,&H00FFFFFF,&H00FFFFFF,&H00000000,&H96000000,-1,0,0,0,100,100,1,0,1,4.5,1.5,2,120,120,96,1
```

## 二、斷句與時間（對齊旁白）

1. 依標點先切子句；只在逗號後、且合併後不超過字數上限時把子句接在同一行。「例如：」這類 ≤3 字的引導語和後面接在一起。
2. 子句太長時，只在**詞與詞之間**換行：頓號優先；其次英文詞前後、虛詞（的、了、是、在、把、到、就、都、也、要、會、讓…）之後、連接詞（和、與、及、或、但、並）之前。產品名（Nano Banana 2.1、Google AI Studio、Gemini App…）不拆。
3. **換行時間對齊旁白停頓**：從旁白音軌找句中停頓（比該句中位數低 18 dB、≥ 80 ms），每一行的開始對到最接近的停頓；找不到停頓才用字數比例估計。程式會回報「對齊停頓／字數估計」各幾處。
4. 每行至少顯示 0.7 秒；太短的行與同句相鄰行合併（不超過字數上限）。
5. 字幕文字以實際配音稿為準；改稿重配後要重新產生。

## 三、字幕安全區（製作畫面時必守）

| 區域（1080p） | 用途 |
|---|---|
| y 16–880 | 畫面內容（圖卡、動畫、模擬介面、標題） |
| **y 880–1000** | **字幕安全區**：不放任何重要文字、標籤、按鈕、引導線 |
| 右下 x ≥ 1552、y ≥ 740 | 黑熊老師講課角色（已存在的規則） |

- `build.py` 預設開啟 `video.subtitle_safe: true`：每張圖卡與 `type: anim` 動畫畫面會等比縮到 80%，水平置中、上緣 16 px，因此任何版型的內容都落在 y 880 以上；深色卡補上同間距格線、淺色卡延伸邊緣背景，不會有接縫。
- `type: photo`：**插圖、圖解、截圖、有文字標籤的圖一律加 `fit: safe`**，整張縮到字幕區以上；只有課堂實景這類「背景照片」維持滿版（字幕可以壓在照片上）。不論哪種，左右面板、下方字卡 `lines`、名牌 `plate` 都會上移到 y 860 以上。
- `type: video`（錄屏、外部片段）不會自動縮放：錄製或擷取時，把重點操作留在畫面上方；需要時在剪輯時縮放。
- 自寫的 HTML／程式動畫（例如 Playwright 逐格動畫）同樣把內容限制在 y ≤ 860，底部留白。
- 不想要字幕區的專案（例如只上無字幕版）可設 `video.subtitle_safe: false`。

## 四、Shorts（直式 1080×1920）

| 項目 | 固定值 |
|---|---|
| 每行字數 | ≤ 12 字，一次一行 |
| 大小 | 72；外框 5.5 px、陰影 2 px，白字黑框無底色 |
| 位置 | 字幕中心約在畫面高度 65%（MarginV 620）；左右邊界 70／140，避開右側按鈕列 |
| 字幕安全區 | y 1150–1330 不放重要內容；y ≥ 1500 會被 Shorts 標題與按鈕蓋住；右側 x ≥ 940 從 y 900 起有按鈕 |

指令：`python scripts/build/subs_oneline.py <專案> --format shorts`。

## 五、產生與交付

- 一鍵：`build_video.bat` 最後一步自動執行 `subs_oneline.py`，輸出：
  - `3_製作後/輸出成品/<名稱>_完整版.mp4`：無字幕版
  - `3_製作後/輸出成品/<名稱>_完整版_單行字幕.mp4`：嵌入字幕版
  - `2_製作中/字幕/字幕_zh-TW_單行.srt`（與 `.ass`）
- 手動：`python scripts/build/subs_oneline.py <專案> [--format shorts] [--no-burn] [--srt X --narration X --video X]`
- **交付兩版**：上 YouTube 建議「無字幕版＋單行 SRT」，觀眾可開關、字幕內容可被搜尋；嵌入字幕版給 Facebook、LINE、課堂播放等無法開字幕的場合。燒錄字幕和 YouTube 字幕同時開會出現兩層，不要兩者並用。
- 歸檔依 `project-layout.md`：兩版成片都放 `製作後/`（檔名加 `_單行字幕`），SRT 放 `製作後/字幕/字幕_zh-TW_單行.srt`。

## 六、驗收

- 抽查淺色與深色畫面各一處：字清楚、只有一行、在 y 880–1000 之間、沒碰到黑熊老師。
- 圖卡在字幕區內只有背景（`subtitle_safe` 開啟時自動成立）；錄屏與自寫動畫要人工看。
- 程式回報的「字數估計」比例偏高時（例如超過三成），抽看那幾行的時間是否跟得上旁白。
- 英文字幕（如果需要）同樣一行，最多約 42 個字元。
