# 頻道設定檔：AI 觀測站（AI Watch）

## 頻道識別
- channel_id: `ai-watch`
- 頻道名稱：AI 觀測站（AI Watch）
- 主要受眾：對 AI、軟體、開源專案和數位創作有興趣的一般觀眾、創作者、開發初學者與科技工作者
- 內容承諾：把 AI 和軟體變化說清楚，並透過實測、示範或開發紀錄，讓觀眾知道如何應用
- 建議頻道短句：看懂 AI 變化，親手做出能用的工具

## 主要內容
1. AI 新趨勢與值得理解的產品更新
2. AI Coding、軟體工程概念與專有名詞
3. 開源軟體與 GitHub 專案實測
4. 網站、App、軟體和系統開發紀錄

## 選題和查證
- 選題要回答：發生了什麼、對誰有用、能否實際測試、觀眾看完能理解或完成什麼。
- 依題目優先使用官方文件、官方公告、原始 GitHub 專案、版本紀錄、研究論文和可重現的實測；媒體文章或社群討論用來補充背景。
- 趨勢資訊標記發布日期、版本、方案／費用、作業系統和地區可用性；會變動的資訊在錄製前再次確認。
- GitHub 專案需實際檢查 README、授權、最近更新、安裝需求、環境變數、安全性和可重現程度；無法測試的部分明確標示。
- 效能、成本、節省時間等數字只有在有實際量測與測試條件時才提出；分清實測結果、官方宣稱和推論。
- 不把「熱門」當作唯一選題理由，也不承諾每個人都能達成相同成果。

## 腳本風格
- 輕鬆、活潑、有活力，帶科技專業感與溫暖幽默；口語但不裝懂、不賣弄術語。
- 每支影片至少加入一個生活或工作情境、一個白話類比，以及一個可見的實測結果或作品。
- 開場先讓觀眾知道本集要解決的問題或要做出的成果；過程交代關鍵設定、卡點、限制與驗證方式。
- 新專有名詞第一次出現時，先用生活例子說明，再補上正式名稱和用途。
- 標題以清楚、可信、具體為優先；可以提出好奇心，但不使用過度聳動、恐嚇或無依據的數字承諾。
- 旁白速度、句長、分段口頭禪和影片長度依內容調整；不強制沿用某一頻道的固定語助詞。

## 品牌影音
- **2026-10-06 使用者定案（優先於下列舊規則）**：片頭、配音、背景音樂與黑熊老師講課角色一律依 `../references/fixed-settings.md`。AI Watch 也使用黑熊老師片頭（`assets/brand-approved/v1/blackbear-science/intro/`）、Achird 固定 Style、原創 lo-fi 配樂，並在右下角疊加黑熊老師講課（`scripts/build/bear_presenter.py`）。先前「AI Watch 不借用自然教室熊掌／黑熊素材」的限制因此取消。
- 片尾：2026-10-02 使用者核定四支主題片尾，正式路徑 `assets/brand-approved/v1/ai-watch/outros/<主題>/outro.mp4`，主題為 trends、tools、coding、opensource，每支六秒、含音樂。依主要題材選一支，以 `scripts/build/append_outro.py` 後製接入（build.py 沒有 outro／outro_audio 欄位）。

- AI Watch 原創 Logo 片頭、通用片尾、音床草案仍留在 `assets/brand-drafts/`，不自動啟用。

社群使用本頻道文案、標籤、CTA；`fb_post.py --channel ai-watch`，英文文案按需求。`thanks` 圖卡填 `name: AI 觀測站（AI Watch）`；結尾自我介紹可用「我是黑熊老師」（使用者腳本即如此）。

## 成效與迭代
- 復盤觀眾留存、搜尋詞、留言中的卡點、實測可重現性與觀眾實際完成率。
- 依資料改善標題、縮圖和教學順序；不以保證流量或固定 CTR 門檻作為內容品質判定。
